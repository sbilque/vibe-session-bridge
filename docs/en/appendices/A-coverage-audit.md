## 1. Claude / Copilot "Continue In"

Source: `src/vs/workbench/contrib/chat/browser/actions/chatContinueInAction.ts`, `agentSessions/agentSessions.ts`, `chatSessions/chatSessions.contribution.ts`.

| VS Code element | Finding | Bridge |
|---|---|---|
| "Continue Chat in…" menu: targets | Only `copilotcli` (Background), `copilot-cloud-agent` (Cloud) and Agent Host types (`agent-host-*`) with `canDelegate` (`getAgentCanContinueIn`, `isAgentHostTarget`) | **C**: a third-party type (`mistral-vibe`) cannot be a menu target |
| Transcript passed on | `buildDelegationTranscript`: `User: …` / `Assistant: …`, last 20,000 characters; for non-Agent-Host targets, inlined in the prompt: "The following is the conversation history from a previous {0} session. Continue working on it. … User: {prompt}"; for the Agent Host, a "Previous conversation" paste attachment | **A**: same format, used in both directions |
| Vibe → other agent | Public commands `workbench.action.chat.delegateToAgentHostSession` `{type, displayName, prompt}` and `workbench.action.chat.openNewSessionEditor.<type>` `{prompt}` | **A**: "Mistral Vibe: Continue in…" command (local Chat, Copilot CLI, Cloud, Claude, Codex, Copilot Agent Host) |
| Vibe → Vibe Code Web | Vibe `/teleport` command (`vibe/acp/commands/registry.py`) | **A**: `/teleport` slash command declared in the session |
| Other agent → Vibe | `openNewSessionEditor.mistral-vibe` / `openSessionWithPrompt.mistral-vibe`, generated by VS Code for every contributed type, with `prompt` + `attachedContext` (paste) | **A**: text (paste) references are passed to Vibe; "Continue in Mistral Vibe" command from a file or selection |
| History received by the participant (`ChatContext.history`) | Copilot CLI summarizes it when delegated to (`copilotCLIChatSessions.ts`) | **A**: new Vibe session with non-empty history → transcript prepended to the first prompt |
| Options passed on (`initialSessionOptions`) | Specific to internal targets | **C** |
| Sub-agents, native Agent Host handoff, worktrees | Internal to the Agent Host | **C** |

## 2. `chatSessions` contribution (`chatSessions.contribution.ts` schema)

| Field | Bridge |
|---|---|
| `type`, `name`, `displayName`, `description`, `when`, `welcome*`, `inputPlaceholder` | ✓ |
| `icon` | **A** |
| `commands` (static slash commands) | **A**: Vibe built-in commands (`registry.py`); `request.command` sent to Vibe as `/cmd …` (`commands/controller.py::execute`) |
| `capabilities.supportsFileAttachments` | ✓ |
| `capabilities.supportsImageAttachments` | **A**: Vibe advertises `promptCapabilities.image`; images converted to an `image` `ContentBlock` (proposed `chatReferenceBinaryData` API) |
| `canDelegate` | **C**: no effect for a third-party type (see 1) |
| `supportsHandOffs`, `customAgentTarget`, `requiresCustomModels` | **C**: specific to Copilot agents |

## 7. Prompt content (`ContentBlock`)

| VS Code reference | Before | 0.1.0 |
|---|---|---|
| File (`Uri`) | `resource_link` | ✓ |
| Selection (`Location` with a range) | `resource_link` to the whole file | **A**: embedded `resource` with the range text (`embeddedContext` advertised) |
| Pasted text / transcript (`string`) | ignored | **A**: embedded text `resource` |
| Image (`ChatReferenceBinaryData`) | ignored | **A**: base64 `image` |
| Slash command | ignored | **A**: `/cmd` at the start of the text |
